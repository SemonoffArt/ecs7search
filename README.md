## 🌟 Описание

**ECS7SEARCH** — легковесное Flask-приложение, разработанное для инженеров и операторов, работающих с **SCADA-системой ABB ECS7**. Вместо ручного открытия десятков файлов мнемосхем, PDF-схем и таблиц I/O для поиска конкретного тега, ECS7SEARCH индексирует все ваши данные один раз и выдаёт **мгновенные визуальные результаты**.

> 💡 Введите тег `020MG021M01` → получите выделенные позиции на каждом экране, где он встречается, а также связанные страницы PDF и записи I/O — всё за миллисекунды.

## ✨ Возможности

### 🎯 Поиск тегов по нескольким источникам
- 🖼️ **Экраны мнемосхем (`.g` файлы)** — поиск тегов по всем мнемосхемам SCADA с **жёлтыми рамками**, нарисованными прямо на скриншотах
- 📄 **PDF-документы** — поиск по схемам, даташитам и инженерной документации; скачивание консолидированных результатов в виде объединённого PDF
- 📊 **Списки I/O (Excel)** — поддержка нескольких файлов с детализацией по листам
- 🔧 **Детали ПЛК** — извлечение метаданных тегов из баз данных ABB FLSA Pro (`.mdb`)

### 🧠 Умный поиск
- 🔤 **Поиск по шаблону** с подстановочными знаками `*` и `?` (например, `020MG*`, `*AF05*`)
- 🎯 **Точное совпадение** для точных запросов
- 🏷️ **Подробный режим** — описания, адреса ПЛК, клеммы I/O, алгоритмы и группы

### ⚡ Современный интерфейс
- 🚀 **Поиск через AJAX** — без перезагрузки страницы, анимированный индикатор загрузки
- 📸 **Масштабируемые изображения** — кликните для увеличения скриншота
- 📥 **Экспорт результатов** в PDF
- 🎨 **Чистый интерфейс на Bootstrap** с адаптивной вёрсткой

### 🛠️ Инструменты администратора
- ⚙️ **Индексация в один клик** из веб-интерфейса (мнемосхемы, PDF, списки I/O, MDB)
- 📊 **Статус индексирования в реальном времени** с отчётом о прогрессе
- 🗄️ **Панель конфигурации** со статистикой по источникам данных

## 🚀 Быстрый старт

### Требования
- **Python 3.10+**
- **[UV](https://github.com/astral-sh/uv)** пакетный менеджер (рекомендуется)
- Windows / Linux / macOS

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/SemonoffArt/ecs7search.git
cd ecs7search

# Установить зависимости через UV
uv sync

# Или через pip
pip install -r requirements.txt
```

### Запуск приложения

```bash
uv run ecs7search.py
# или
uv run flask --app ecs7search run
```

🌐 Откройте [http://localhost:5000](http://localhost:5000) в браузере и начните поиск!

## ⚙️ Конфигурация

Приложение использует файловую конфигурацию — все источники данных находятся в `data/`:

| Файл                            | Описание                                   |
|---------------------------------|--------------------------------------------|
| `data/mimics/`                  | `.g` файлы SCADA + `.png` скриншоты        |
| `data/mimics_index.json`        | Сгенерированный индекс тег → позиция       |
| `data/pdf/`                     | Технические PDF-документы                  |
| `data/pdf_index.json`           | Индекс тегов PDF                           |
| `data/IO_list*.xlsx`            | Множественные списки I/O (поддерживается)  |
| `data/io_list.json`             | Объединённый индекс сигналов I/O           |
| `data/FlsaProDb/*.mdb`          | Базы данных тегов ABB FLSA Pro             |
| `data/tags.json`                | Извлечённые метаданные тегов               |

Все индексы можно перестроить на странице **Настройки** в веб-интерфейсе (кнопка ⚙️).

## 🧭 Примеры использования

### Поиск одного тега

```
020MG021M01
```
Возвращает все мнемосхемы, PDF и записи I/O для этого конкретного тега.

### Поиск по шаблону с подстановочными знаками

```
020MG*          → все теги, начинающиеся с 020MG
*AF05*          → все теги, содержащие AF05
020??021M01     → гибкое позиционное совпадение
```

### Подробный режим
Включите флажок **"Информация по тегам"**, чтобы увидеть:
- 📖 Описания тегов (EN / RU)
- 🏭 Адрес ПЛК (DB, FC, биты ввода/вывода)
- ⚙️ Алгоритмы (Conv / Calc / Block)
- 🔌 Детали клемм I/O
- 🖥️ Список экранов
