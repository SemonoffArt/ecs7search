## 🌟 Описание

**ECS7SEARCH** — легковесное Flask-приложение, разработанное для инженеров и операторов, работающих с **SCADA-системами FLS ECS7 (ЗИФ1) и ECS8 (ЗИФ2)**. Вместо ручного открытия десятков файлов мнемосхем, PDF-схем и таблиц I/O для поиска конкретного тега, ECS7SEARCH индексирует все ваши данные один раз и выдаёт **мгновенные визуальные результаты** — как для ЗИФ1, так и для ЗИФ2, включая аналитику аварий Bus Fault.

> 💡 Введите тег `020MG021M01` → получите выделенные позиции на каждом экране, где он встречается, а также связанные страницы PDF и записи I/O — всё за миллисекунды.

## ✨ Возможности

### 🎯 Поиск тегов по нескольким источникам
- 🖼️ **Экраны мнемосхем ЗИФ1 (`.g` файлы)** — поиск тегов по всем мнемосхемам SCADA с **жёлтыми рамками**, нарисованными прямо на скриншотах
- 📄 **PDF-документы ЗИФ1 и ЗИФ2** — поиск по схемам, даташитам и инженерной документации; скачивание консолидированных результатов в виде объединённого PDF
- 📊 **Списки I/O ЗИФ1 (Excel)** — поддержка нескольких файлов `IO_list*.xlsx` с детализацией по листам
- 📋 **Списки I/O ЗИФ2 (Excel)** — несколько файлов `IO-List-*.xlsx` с полями «Шкаф», «Клеммник», «IO-адрес», «Тип», «Описание»
- 📈 **Точки ЗИФ2 (`Points.xlsx`)** — поиск по справочнику точек с функциональной иерархией, алиасами и типами
- 🔧 **Детали ПЛК** — извлечение метаданных тегов из баз данных ABB FLSA Pro (`.mdb`)

### 🧠 Умный поиск
- 🔤 **Поиск по шаблону** с подстановочными знаками `*` и `?` (например, `020MG*`, `*AF05*`)
- 🎯 **Точное совпадение** для точных запросов
- 🔀 **Переключатель ЗИФ1 / ЗИФ2** — единый поиск по разным установкам
- 🏷️ **Подробный режим** — описания, адреса ПЛК, клеммы I/O, алгоритмы, группы и функциональная иерархия

### ⚡ Аналитика аварий ECS8 Bus Fault
- 📥 **Импорт CSV-журналов событий** — выгрузки Event Historian из `data/zif2/ecs8busfaults/`
- 📊 **Сводная аналитика** — динамика по месяцам и дням, топ тегов, кластеры удалённых станций
- 🔎 **Фильтры** — по тегу, периоду, признаку «Running → Bus Fault»
- 🧭 **Обогащение данными сети** — IP-адрес и удалённая станция из `net/*.md`

### 🚫 Теги без экрана
- 🔍 **Поиск тегов**, присутствующих в справочнике (`tags.json`), но не встречающихся ни в одном `.g` файле мнемосхем
- 📊 **Статистика сканирования** — количество проверенных тегов, просканированных файлов и время выполнения
- 🔘 **Фильтр «Только «А» точки»** — отображает только теги с положительным `Id`
- 🔘 **Фильтр «Не показывать PID»** — скрывает теги, заканчивающиеся на `SPM`, `SPMH`, `SPAH`, `SPA` (по умолчанию включён)

### ⚡ Современный интерфейс
- 🚀 **Поиск через AJAX** — без перезагрузки страницы, анимированный индикатор загрузки
- 📸 **Масштабируемые изображения** — кликните для увеличения скриншота
- 📥 **Экспорт результатов** в PDF
- 🎨 **Чистый интерфейс** с адаптивной вёрсткой

### 🛠️ Инструменты администратора
- ⚙️ **Индексация в один клик** из веб-интерфейса (мнемосхемы, PDF ЗИФ1/ЗИФ2, списки I/O ЗИФ1/ЗИФ2, точки ЗИФ2, MDB, Bus Fault)
- 📊 **Состояние индексов** — карточки с количеством файлов, тегов, событий и датами создания по ЗИФ1 и ЗИФ2
- 📊 **Статус индексирования в реальном времени** с отчётом о прогрессе
- 🗄️ **Панель конфигурации** со статистикой по источникам данных и путями к данным

## 🚀 Быстрый старт

### Требования
- **Python 3.10+**
- **[UV](https://github.com/astral-sh/uv)** пакетный менеджер (рекомендуется)
- Windows / Linux / macOS

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/SemonoffArt/ecs7search.git
cd ecs7search

# Установить зависимости через UV
uv sync

# Или через pip
pip install -r requirements.txt
```

### Запуск приложения

```bash
uv run ecs7search.py
```

🌐 Откройте [http://localhost:5942](http://localhost:5942) в браузере и начните поиск!

### Переменные окружения

| Переменная   | По умолчанию | Описание                                  |
|--------------|--------------|-------------------------------------------|
| `ECS7_HOST`  | `0.0.0.0`    | Адрес прослушивания сервера               |
| `ECS7_PORT`  | `5942`       | Порт веб-сервера                          |
| `ECS7_DEBUG` | `0`          | `1` — включить режим отладки Flask         |

> 🪟 Для работы с базами `.mdb` в Windows требуется драйвер **Microsoft Access Driver (\*.mdb, \*.accdb)** (ODBC).

## ⚙️ Конфигурация

Приложение использует файловую конфигурацию. Источники данных разделены по установкам: ЗИФ1 в `data/zif1/`, ЗИФ2 в `data/zif2/`.

### ЗИФ1 (`data/zif1/`)

| Файл                                       | Описание                              |
|--------------------------------------------|---------------------------------------|
| `mimics/`                                  | `.g` файлы SCADA + `.png` скриншоты   |
| `mimics_index.json`                        | Сгенерированный индекс тег → позиция  |
| `pdf/`                                     | Технические PDF-документы             |
| `pdf_index.json`                           | Индекс тегов PDF                      |
| `IO_list*.xlsx`                            | Множественные списки I/O              |
| `io_list.json`                             | Объединённый индекс сигналов I/O      |
| `FlsaProDb/*.mdb`                          | Базы данных тегов ABB FLSA Pro        |
| `tags.json`                                | Извлечённые метаданные тегов (MDB)    |
| `tags_without_screen_index.json`           | Индекс тегов без экранов              |

### ЗИФ2 (`data/zif2/`)

| Файл                                       | Описание                              |
|--------------------------------------------|---------------------------------------|
| `pdf/`                                     | Технические PDF-документы             |
| `pdf_index.json`                           | Индекс тегов PDF                      |
| `IO-List-*.xlsx`                           | Списки I/O                            |
| `Points.xlsx`                              | Справочник точек                      |
| `points.json`                              | Индекс точек (`Designation` → поля)   |
| `ecs8busfaults/`                           | CSV-журналы событий Bus Fault + `net/`|
| `bus_fault_events.json`                    | Индекс событий Bus Fault              |

Все индексы можно перестроить на странице **Настройки** в веб-интерфейсе (кнопка ⚙️).

## 🧭 Примеры использования

### Поиск одного тега

```
020MG021M01
```
Возвращает все мнемосхемы, PDF и записи I/O для этого конкретного тега. Переключатель **ЗИФ1 / ЗИФ2** меняет набор источников (мнемосхемы и `tags.json` для ЗИФ1, `points.json` и списки I/O для ЗИФ2).

### Поиск по шаблону с подстановочными знаками

```
020MG*          → все теги, начинающиеся с 020MG
*AF05*          → все теги, содержащие AF05
020??021M01     → гибкое позиционное совпадение
```

### Подробный режим
Включите флажок **"Информация по тегам"**, чтобы увидеть:
- 📖 Описания тегов (EN / RU)
- 🏭 Адрес ПЛК (DB, FC, биты ввода/вывода) — ЗИФ1
- ⚙️ Алгоритмы (Conv / Calc / Block) — ЗИФ1
- 🔌 Детали клемм I/O
- 🖥️ Список экранов — ЗИФ1
- 🧩 Функциональную иерархию и тип точки — ЗИФ2

### Аналитика Bus Fault (ЗИФ2)
Перейдите на страницу **«ECS8 BusFaults»** в навигации:
1. Скопируйте CSV-выгрузки Event Historian в `data/zif2/ecs8busfaults/`.
2. Нажмите **«Переиндексировать CSV»**.
3. Анализируйте динамику аварий, топ тегов и кластеры удалённых станций с фильтрами по тегу и периоду.

### Теги без экрана
Перейдите на страницу **«Теги без экрана»** в навигации:
1. Нажмите кнопку **🔍 Поиск** для сканирования всех `.g` файлов
2. Получите таблицу тегов из `tags.json`, отсутствующих на мнемосхемах
3. Используйте фильтры для точной настройки вывода:
   - **Только «А» точки** — показать теги с `Id > 0`
   - **Не показывать PID** — скрыть теги с суффиксами `SPM`, `SPMH`, `SPAH`, `SPA`
