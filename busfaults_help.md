# Инструкция по копированию событий из ECS8 в анализатор BusFaults

Анализатор аварий «busfaults» для ЗИФ2 находится по адресу:  
`http://10.100.59.40:5942/busfaults`

## Общий принцип работы

Для обновления базы событий ECS необходимо:

1. Выгрузить события из SCADA в формате CSV.
2. Скопировать файлы в специальную папку со скриптом.
3. Запустить переиндексацию через веб-интерфейс анализатора.

Скрипт автоматически обрабатывает **все CSV-файлы** в указанной папке.  
Дублирование записей исключено — скрипт проверяет уникальность данных.

---

## 1. Выгрузка событий из ECS8

1. Откройте **Event Historian**.
2. Очистите поле **Tag Filter** (удалите всё содержимое).
3. Установите уровень **Severity** в положение **«urgent»** (красный значок с крестом).
4. Настройте чекбоксы (оставьте отмеченными только указанные ниже, остальные снимите):
   - ✅ **Kind** → *Process*
   - ✅ **Class** → *Condition*
5. В разделе **Hierarchy** снимите галочку с **System**.
6. Нажмите кнопку **Search**.
7. Нажмите кнопку **Export**.
8. Выберите период выгрузки:
   - **Не более одного месяца** (иначе ECS может не завершить операцию).
   - Формат: **CSV**.
9. Дождитесь завершения обработки (несколько минут).
   - Система предложит выбрать место для сохранения файла.
   - **Если через 5 минут окно сохранения не появилось**:
     - Закройте окно ECS.
     - Откройте его снова.
     - Выберите меньший диапазон времени и повторите попытку.

---

## 2. Индексирование событий скриптом

1. Скопируйте выгруженные CSV-файлы в папку со скриптом:  
   `C:\Users\asutp\Desktop\7art\ecs7search\data\ecs8busfaults\`
2. Откройте веб-страницу анализатора:  
   `http://10.100.59.40:5942/busfaults`
3. Нажмите кнопку **«Переиндексировать CSV»**.

После этого скрипт обработает все новые файлы и обновит данные анализатора.
